# @lsby/lens-box-formal-logic-lens

从**形式逻辑视角**对文本进行分析的透镜

## 观察视角

不同于统计词汇分布的语义学视角或剖析论证结构的论证视角，本透镜把一段发言当作**可被形式化的逻辑断言集合**来观察，回答两个问题：

1. **发言明确断言了哪些命题？**（每条命题附自然语言重述与逐字原文依据）
2. **这些命题的形式逻辑结构是什么？**（命题逻辑与一阶谓词逻辑公式：原子、联结词、量词，本地解析为 AST）

## 核心领域概念

- **`FormalProposition`**：一条被形式化的命题实体，内聚自然语言内容、**逐字原文依据**（`quote` + `[start, end)` 字符区间）、形式逻辑公式（源串 + 构造时解析校验的 AST，强制闭公式约束）与可选**翻译备注**（`note`，记录歧义备选读法、模态词权宜处理等），支持关键词匹配、谓词元数与常量查询、快照导出。
- **`FormalLogicDocument`**：一次剖析的完整结果，聚合原文、命题列表、来源标签、记录时间与提取来源（模型与提示词版本）；构造时重新校验每条原文依据与原文逐字一致、每条公式仍为闭公式，并强制**全文档谓词元数一致**（同一谓词符号不得以不同元数出现）；提供 `listPredicateSymbols()`（谓词符号及元数）与 `listConstants()`（常量表）两份词汇表。
- **`FormalLogicLens`**：无状态对外入口，基于 `@lsby/ai-agent`（接收标准 OpenAI 兼容客户端与模型配置）发起结构化提取并返回 `FormalLogicDocument`。
- **`buildFormalLogicDocument`**：纯本地构建函数，将固定提取结果离线构建为 `FormalLogicDocument`，供测试与自定义提取通道复用。
- **`parseFormula` / `formatFormula`**：公式字符串 ↔ AST 的确定性互转；`findFreeVariables`、`collectPredicateArities`、`collectConstants` 提供良构性校验与词汇收集原语。

## 公式语法

- **原子**：裸标识符（0 元原子命题，如 `P`、`下雨`）或谓词应用 `谓词(项, ...)`（如 `人(苏格拉底)`、`喜欢(张三, 李四)`）。
- **标识符与项**：标识符以 Unicode 字母开头，可含字母、数字、下划线；项为标识符，其中**单个小写拉丁字母**（`x`、`y`、`z`……）是变量，其余标识符是常量。
- **联结词**（优先级高 → 低）：`¬` > `∧` > `∨` > `→` > `↔`；`→`、`↔` 右结合；`()` 分组。别名：`~`/`!`（¬）、`&`/`&&`（∧）、`|`/`||`（∨）、`->`（→）、`<->`（↔）。
- **量词**：`∀x` / `∃x`（别名 `forall x` / `exists x`），只能绑定单个小写拉丁字母变量，与 `¬` 同级、仅约束紧随的子公式（范围有歧义时请用括号）。
- **闭公式约束**：命题公式中所有变量必须被量词绑定，存在自由变量即非法。
- **渲染约定**：`formatFormula` 输出**完整括号**的规范化字符串（二元联结词一律 `(L op R)`），不依赖优先级约定即可无歧义阅读。

## 翻译约定

提取模型在翻译时遵循以下约定（完整表述见系统提示词；变更会递增 `FORMAL_LOGIC_PROMPT_VERSION`）：

- **论域守卫**：量化特定类别对象时在公式体内显式声明论域，如 `∀x (人(x) → 通过考核(x))`。
- **不相容选言**："要么 A，要么 B"译作 `(A ∨ B) ∧ ¬(A ∧ B)`；相容的"或"才使用 `∨`。
- **关系性质与元语言陈述**：如"认识关系具有传递性""上述命题不一致"，能对象语言化就用 FOL 表达（如 `∀x∀y∀z ((认识(x, y) ∧ 认识(y, z)) → 认识(x, z))`），无法时保留 0 元命题变元并在 `note` 中说明。
- **模态词**：可能、必须、禁止等模态词扁平化为普通谓词或 0 元变元（权宜处理），并在 `note` 中注明。
- **歧义句**：作用域存在多种读法时（如"除非……也不……"），翻译最自然的一种读法，备选读法写入 `note`。

## 错误语义与副作用

- `analyze()` 会通过网络调用 OpenAI 兼容模型，**可能产生模型费用**；公式解析、构建、查询与快照恢复均为纯本地操作。
- 输入为空、模型无法给出有效结构化结果、公式非法或违反闭公式约束、提取结果引用重复临时标识、原文摘录无法按出现序号定位、谓词元数冲突、快照中的依据与原文不一致等场景均**立即抛错**（Fail-Fast），不做静默兜底；网络、限流与中断异常原样向上传播。
- 非法公式在结构化输出的 Schema 校验阶段（`superRefine`）即被拦截并反馈给模型重试修复，进入本地构建的公式必然可解析。
- 重复调用 `analyze()` 会为相同文本生成新的文档标识与记录时间；透镜不自动持久化任何结果。
- 快照携带 `snapshotVersion: 1` 与 `provenance`（模型名 + 提示词版本 `FORMAL_LOGIC_PROMPT_VERSION`），便于审计与复现；快照只存公式源串，恢复时重新解析并重新校验全部不变量。旧版本快照（命题缺少 `note` 字段）仍可恢复，自动补 `null`。

## 适用边界

- **擅长**：发言、议论、规则陈述等显式断言内容的形式化表示、逻辑结构检索（按谓词符号/关键词）、跨文本命题快照管理。
- **不擅长**：事实真伪核查、隐含前提自动补全、处理不含断言内容的文本（纯疑问、感叹等）

## 特殊适用规则

- **单读法原则**：每条命题只承载一种（最自然的）读法，不自动展开多解读；歧义句的备选读法以 `note` 备注形式提供。
