# @lens-box/psychology-style-lens

从**心理学视角**对文本例句进行文风建模的底层透镜库，采用本体驱动的充血对象建模设计。

## 观察视角

不同于只统计字数、句式长度的语言学视角，本透镜认为**文风的深层驱动力来自“特定性格的人”在“特定心理场景与人际关系”下的表达选择**。

对每一段输入例句，本透镜关注两个核心维度：

1. **人物性格画像**：主导特质、情绪基调、潜台词/表达动机、心理防御或互动姿态。
2. **对话场景环境**：场景类型、社交距离（亲密 / 熟络 / 礼貌 / 疏离 / 对抗）、权力位阶（上位 / 平级 / 下位 / 模糊）、气氛张力。

## 核心领域概念

- **`心理学文风样本`**：代表一条已剖析并沉淀下来的例句实体，内聚了性格、场景语义匹配与快照导出能力。
- **`心理学样本档案`**：代表一组文风样本的聚合容器，负责防重收录、按性格/场景/组合条件检索、画像分布归纳以及 JSON 快照恢复。
- **`心理学文风透镜`**：基于 `@lsby/ai-agent`（接收标准 OpenAI 兼容客户端与模型配置）与 `心理学样本档案`，负责发起心理学剖析、结构化提取并将结果沉淀进档案。

## 适用边界

- **擅长**：角色台词、第一人称独白、带有明显人际互动与情绪张力的叙事文本。
- **不擅长**：纯客观技术文档、无人物立场的百科条目、极短且脱离上下文的无意义碎片。
