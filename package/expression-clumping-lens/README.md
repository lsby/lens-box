# @lsby/lens-box-expression-clumping-lens

基于**字面计数、泊松预期与语料内同频抽样校准**的非大模型表达成团分析透镜，全程同步运行。

## 观察视角

不依赖大语言模型、词典或外部语料，直接统计指定词句在多篇文档中的分布情况，并与同一语料里出现次数相近的其他字串做对比，回答三个问题：

1. **这个表达出现了多少次、落在哪几篇里？**（统计总次数、覆盖篇数以及每篇的命中次数）
2. **它比“同频的普通字串”更集中还是更分散？**（先算随机均匀分布下的泊松期望覆盖篇数，再用同语料抽样得到的经验校准系数修正文风、模板等基线偏差，得出 `成团分数`）
3. **集中出现的表达值得回看哪些原文？**（通过命中分布定位到具体文档序号，便于调用方回读原文语境或为联想图标签补充覆盖分布）

> 直观理解：同样在 8 篇记录里出现 3 次，若“门口”分散在 3 篇里，而“开窍”集中落在某 2 篇里，“开窍”的成团程度就更高。

## 核心领域概念与用法

- **`成团语料`**：基于一组已切分好的非空文本（至少 2 篇，如章节、会话或按天记录）构建的分析语料。构造时会在语料内部完成一次同频参照抽样，之后可反复调用 `观察(表达)` 查询不同词句。
- **`成团观察`**：单次查询的返回结果，包含 `文档数`、`总次数`、`覆盖篇数`、`分布`（命中的 `文档序号` 与 `次数`）以及校准状态：
  - 若 `总次数` 为 `0`、`1～2` 次或没有足够样本的参照档位，状态为 `'未出现'` / `'出现不足三次'` / `'缺少参照'`，`成团分数` 为 `null`。
  - 若满足条件，状态为 `'已校准'`，返回 `成团分数`、`目标档位`、`参照`、`泊松期望篇数` 与 `校准期望篇数`。

```ts
import { 成团语料 } from '@lsby/lens-box-expression-clumping-lens'

let 语料 = new 成团语料(文档列表, { 种子: 1, 样本上限: 3000 })
let 结果 = 语料.观察('开窍')

if (结果.状态 === '已校准') {
  console.log(结果.总次数, 结果.覆盖篇数, 结果.成团分数)
  console.log(结果.分布, 结果.目标档位, 结果.参照)
}
```

## 适用边界

- **擅长**：从写作样本、对话记录或日志中找出集中在少数篇章反复出现的惯用语，定位其所在篇目，或为联想图标签补充覆盖分布特征。
- **不擅长**：同义词或近义表达合并（仅做严格字面匹配）、仅有 1～2 次偶发出现且无法统计成团趋势的词、不依赖切分粒度的绝对指标（更换切分单位需重建语料，跨语料比较需同时参考文档数与参照信息）。

## 统计口径与配置

- **匹配规则**：按原始字面精确匹配，区分大小写、允许重叠计数；查询词须为单行且两端无空白（跨行及文档边界不相连）。同一篇内多次出现会累加 `总次数`，`覆盖篇数` 仅计 1 次。
- **抽样与配置**：支持 `种子`（整数 `0～0xffffffff`，默认 `1`）与 `样本上限`（整数 `1～100000`，默认 `3000`）。构造时在原文中随机抽取 2～4 个 Unicode 码点、不跨行且两端无空白的去重字串作为参照，固定文档顺序、文本、选项与实现版本即可复现。
- **校准与成团分数**：
  - 泊松期望覆盖篇数：`E(cf) = N × (1 − exp(−cf/N))`，其中 `N` 为文档数、`cf` 为总次数。
  - 将出现至少 3 次的参照串按 `floor(log2(cf))` 分档，每档至少需要 5 个不同字串，取 `覆盖篇数 / E(cf)` 的上中位数作为校准系数 `u`（目标档样本不足时借用最近的有效档，等距时取小档）。
  - 成团分数：`C = ln(校准期望篇数 / 覆盖篇数)`。正值越大表示越集中（例如 `C ≈ 0.69` 表示实际覆盖篇数约为校准参照的一半）；`0` 附近表示与同频参照相当；负值表示比参照更分散。

## 背景与测试资料

- **来源说明**：本包将 [Hikaru 的原实现](https://github.com/ikarugaikoi/hikaru-memory/blob/main/.tools/_koyori.py) 中可复用的覆盖统计与校准公式独立为 TypeScript 版本（在字面边界、大小写处理及抽样序列上与原 Python 实现存在差异，具体词数值可能不同）。
- **测试与复现**：详见 [测试结果、合成材料与复现命令](./test-results.md)；运行 `pnpm --filter @lsby/lens-box-expression-clumping-lens demo` 可执行基础演示。
