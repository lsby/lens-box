# @lens-box/semantics-lens

基于**分布语义学与概念共现网络**的非大模型文章语义剖析透镜，采用本体驱动的充血对象建模设计。

## 观察视角

不依赖大语言模型二次生成，直接从文本本身的词汇分布、共现结构与推进轨迹出发，回答三个语义学问题：

1. **文章围绕什么核心概念展开？**（通过词法切分与 TextRank 共现图提取核心概念及其关联邻域、意象簇）
2. **语义是如何随句子/段落推进的？**（通过相邻语义单元的词面重叠度或可选语义向量，计算连贯度曲线、主题收敛度与语义转折点）
3. **多篇文章之间的语义差异是什么？**（通过 `语义档案` 计算跨篇章的语料库级 TF-IDF 独特概念与概念重合度）

## 核心领域概念

- **`语义单元`**：文章切分后的最小语义片段（句子或段落），内聚词频密度、概念匹配与向量/词面相似度计算。
- **`概念共现图`**：基于滑动共现窗口构建的无向加权图，支持 TextRank 核心概念排序、语义邻域查询与局部概念簇识别。
- **`语义篇章`**：整篇文章的语义模型，组合有序 `语义单元[]` 与 `概念共现图`，提供连贯度曲线、转折点定位、收敛度评估与篇章对比能力。
- **`语义档案`**：跨篇章的语料库容器，提供防重收录、按标签检索及语料库级 TF-IDF 独特概念提取能力。
- **`语义学透镜`**：对外剖析入口，内置基于 `@node-rs/jieba`（词性标注实词提取）与 `stopwords-zh` 的词法过滤管道，并结合 `graphology` Louvain 社区发现识别语义子主题簇，同时支持可选注入自定义分词器或向量化函数。

## 适用边界

- **擅长**：长短文章、散文、议论文、叙事片段的结构化语义骨架提取、连贯度与转折点分析、跨文本概念对比。
- **不擅长**：依赖深层常识推理的反讽/隐喻识别、极短无实词感叹句。
